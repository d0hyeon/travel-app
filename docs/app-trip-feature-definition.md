# 앱 여행 상세 기능 정의서

기준: `apps/waylog-web/src/features/trip/TripDetailPage.mobile.tsx`와 각 탭의
모바일 구현. 앱은 Expo Router의 5개 탭으로 같은 기능을 제공해야 한다.

## 공통 탭 플로우

| 액션 | 기대 동작 | 앱 판정 |
| --- | --- | --- |
| 정보·장소·계획·정산·사진 탭 선택 | 현재 여행의 해당 탭으로 전환하고 선택 상태를 표시 | 구현 |
| 여행 이름 영역 | 여행 이름 편집 플로우 진입 | 구현 완료 |
| 채팅 버튼 | 여행 채팅 진입 | 2단계 제외 (`trip-chat`) |
| 로딩 실패 | 오류 메시지와 재시도 제공 | 구현 완료 |

## 정보 탭

| 액션/영역 | 기대 동작 | 앱 판정 |
| --- | --- | --- |
| 기본정보·체크리스트·메모 선택 | 정보 탭 내부 상태를 유지한 채 콘텐츠 전환 | 구현 |
| D-Day | 여행 기간에 따른 D-Day 표시 | 구현 |
| 여행 정보 카드 | 기간·목적지 등 여행 기본 정보 표시 | 구현 |
| 해야 할 일 | 마감 임박/초과 상태와 담당자 표시 | 구현 |
| 체크리스트 추가·수정·완료·삭제 | 바텀시트 폼, 확인 후 삭제, 체크 토글 | 구현 |
| 고정 메모 | 고정 메모 목록 표시 | 구현 |
| 메모 목록·추가·상세·수정 | 메모 추가 바텀시트 및 상세 화면 이동 | 상세·수정 라우트 구현 완료 |
| 여행 멤버·초대 | 초대 플로우와 멤버 목록 표시 | 구현 |
| 여행에서 나가기 | 확인 후 호스트는 삭제, 멤버는 나가기, 목록으로 이동 | 수정 완료 |
| 종료 여행 회고 포스트 카드 | 종료된 여행에서 포스트 작성 화면으로 이동 | 앱 포스트 작성 기능은 후속 단계 의존성으로 보류 |
| 추천 장소·커뮤니티 경로 | 추천 콘텐츠 표시 및 상세 플로우 | 2단계 예외 (`trip-recommend`, `trip-community-routes`) |

## 장소 탭

| 액션/영역 | 기대 동작 | 앱 판정 |
| --- | --- | --- |
| 지도 마커 | 장소 선택 및 포커스 | 구현 |
| 장소 목록 항목 | 지도 중심을 해당 장소로 이동 | 구현 |
| 확정/후보 분류 | 경로 포함 여부에 따른 목록과 개수 표시 | 구현 |
| 바텀시트 스냅 | 25/50/80/100% 스냅 및 지도 재배치 | 구현, RN 오프셋 차이 확인 |
| 장소 추가 | 검색·장소 폼·저장 후 지도 포커스 | 구현 |
| 지도 렌더링 | 앱은 Google 지도만 사용 | 앱 제약으로 웹 Kakao 분기 차이는 예외 |
| 장소 검색 | 장소 검색 provider로 Google/Kakao 모두 지원 | 구현 — 지역에 따라 provider 선택 |
| 경로찾기 | 도로 경로 provider로 Google/Kakao 모두 지원 | 구현 — 도메인 road-route provider 사용 |
| 추천 마커·추천 장소 상세 | 추천 장소 마커와 상세 바텀시트 | 2단계 예외 |

## 계획 탭

| 액션/영역 | 기대 동작 | 앱 판정 |
| --- | --- | --- |
| 여행 날짜 선택 | 날짜 전환 및 경로 선택 초기화 | 수정 완료 |
| 경로 선택 | 경로 전환 | 구현 |
| 경로 추가·삭제 | 경로 생성 및 삭제 | 구현 |
| 지도 장소 선택 | 경로 추가/제거 액션 제공 | 구현 완료 |
| 장소 순서 드래그 | 순서 저장 | 구현 — 낙관적 UI는 기존 버그로 의도적으로 사용하지 않음 |
| 장소 표시/숨김 | 경로 계산·지도 표시에서 토글 | 구현 |
| 장소 메모 | 메모 추가·수정·삭제 | 구현 |
| 경로 기반 지도·현재 위치 | 현재 위치 이동 및 가까운 장소 포커스 | 구현 완료 |
| 날씨·해양 활동 | 날씨/해양 활동 표시 | 2단계 예외 (`trip-weather`, `trip-marine-activity`) |

## 정산 탭

| 액션/영역 | 기대 동작 | 앱 판정 |
| --- | --- | --- |
| 총 지출 헤더 | KRW 환산 총액 표시 | 구현 |
| 해외 환율 | 사용 통화별 환율 조회·수정 | 구현 |
| 지출 내역 | 지출 목록·참여자·결제자 표시 | 구현 |
| 지출 추가 | 폼 바텀시트 저장 | 구현 |
| 지출 수정·삭제 | 메뉴에서 수정/삭제, 삭제 확인 | 구현 |
| 정산 | 개인별 잔액과 송금 안내 표시 | 구현 |
| 경로 기반 지출 | 바텀시트로 장소별 지출 표시 | 구현 완료 |
| 멤버 없음 | 안내 문구와 액션 비활성화 | 수정 완료 |
