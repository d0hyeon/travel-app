# 교통편 등록 데스크톱 화면 설계

## 목표

교통편 등록을 모바일 화면의 확장판이 아닌, 독립된 데스크톱 입력 화면으로 제공한다.
좌측 뒤로가기와 화면 제목·단계 표시는 공용 데스크톱 내비게이션을 사용한다.

## 책임과 소유권

- `useTransportForm`은 교통수단 종류와 상세 입력 초안을 보관한다. 등록 단계, URL, 화면 이동, 저장 요청은 소유하지 않는다.
- `TransportFormPage`는 등록 퍼널을 조정한다. URL 단계값을 읽고, 단계 간 이동·이전 화면 이동·저장 성공 뒤 목록 복귀를 결정한다.
- 모바일·데스크톱 페이지는 각 기기에 맞는 프레임만 표현한다. 등록 상태나 단계 제어 정책을 다시 구현하지 않는다.
- `TopNavigation`은 공통 상단 내비게이션과 기본 뒤로가기 규칙을 책임진다. 특정 화면의 이동 목적지는 상위 화면이 `onClick`으로 결정할 수 있다.

## 화면 구조

데스크톱 페이지는 전체 배경 위에 제한된 폭의 입력 영역을 둔다. 상단에는 공용 데스크톱 내비게이션을 배치하고, 좌측에는 뒤로가기, 본문에는 `교통편 등록`, 우측에는 단계 표시를 둔다. 입력 단계 콘텐츠는 현재 퍼널과 동일하게 유지한다.

모바일은 기존 고정 상단 내비게이션과 전체 폭 레이아웃을 유지한다.

## 변경 범위

- `features/trip/trip-transport/transport-form/useTransportForm.ts`: 등록 입력 초안 상태를 소유한다.
- `features/trip/trip-transport/transport-form/TransportFormPage.tsx`: 단계·저장·이동을 조정하고 입력 상태 훅을 사용한다.
- `features/trip/trip-transport/transport-form/TransportFormPage.desktop.tsx`: 데스크톱 프레임을 표현한다.
- `shared/components/layout/TopNavigation.desktop.tsx`: 전달된 클릭 동작을 보존하고, 기본 뒤로가기 규칙을 모바일과 일치시킨다.
- `docs/codebase.md`: 교통편 등록의 기기 분기와 입력 상태 소유 위치를 갱신한다.

## 검증

- 데스크톱에서 등록 화면은 공용 상단 내비게이션의 좌측 뒤로가기·제목·단계 표시를 갖는다.
- 데스크톱 뒤로가기는 이전 화면으로 이동하고, 직접 진입 시 홈으로 이동한다.
- 종류·상세·탑승권의 단계 전환과 저장 성공 후 교통편 목록 복귀가 유지된다.
- 모바일 등록 화면의 레이아웃과 동작은 변하지 않는다.
- TypeScript 검사와 웹 빌드를 통과한다.
