# 교통편 상세 화면 전환 설계

## 목표

교통편 상세를 오버레이가 아닌 독립 라우트로 열고, 앱과 웹에서 같은 정보 구조를 제공한다.
목록과 다가오는 교통편 카드의 선택은 항상 이 상세 라우트로 이동한다.

## 구현 순서

1. 앱과 웹에 `tripId`·`transportId`를 받는 교통편 상세 라우트를 추가한다.
   - 완료 기준: 직접 URL로 열었을 때 해당 교통편을 조회해 화면을 렌더링한다.
2. 기존 상세 오버레이 진입점을 새 라우트 이동으로 바꾼다.
   - 완료 기준: 목록 카드와 다가오는 교통편 카드에서 바텀시트·다이얼로그가 열리지 않는다.
3. 상세 본문을 시안의 정보 구조로 구현한다.
   - 완료 기준: 헤더, 시간·노선, 시안 전용 정보 블록, 티켓 영역, 길찾기 행이 순서대로 보인다.

## 라우트와 소유

| 플랫폼 | 라우트 | 화면 소유 위치 |
| --- | --- | --- |
| 앱 | `/trip/[tripId]/transport/[transportId]` | `features/trip/trip-transport/` |
| 웹 | `/trip/:tripId/transport/:transportId` | `features/trip/trip-transport/` |

화면은 `transportId`만으로 필요한 교통편·멤버 데이터를 조회한다. 호출부는 교통편 객체를 조립하거나 전달하지 않는다. 이는 목록·다가오는 카드·직접 URL 진입이 같은 화면을 사용하게 하기 위함이다.

## 시안 매핑

실제 데이터는 교통수단 종류, 예정 시각, 출발·도착지, 운항사·편명, 티켓, 멤버만 사용한다.
실시간 지연, 터미널, 게이트, 좌석은 현재 도메인 모델에 없으므로 화면 형태를 맞추는 정적 UI로만 둔다. 이 값은 저장·수정·알림에 사용하지 않는다.

| 시안 영역 | 구현 규칙 |
| --- | --- |
| 헤더 | 뒤로가기, `항공 상세` 같은 종류 기반 제목, 더보기 아이콘을 표시한다. |
| 운항 정보 | 타입 배지, 큰 출발·도착 시각, 노선, 운항사·편명·출발 날짜를 표시한다. |
| 시안 전용 블록 | 실시간 정보와 3개 정보 카드는 정적 값으로 렌더링한다. |
| 티켓 | 내 티켓은 강조 버튼, 동행 티켓은 멤버 행으로 표시한다. 기존 이미지 뷰어 연결은 이번 UI 전환 범위에서 제외한다. |
| 길찾기 | 테두리 행을 표시한다. 실제 지도 이동은 이번 UI 전환 범위에서 제외한다. |

## 범위 밖

- 실시간 운항 정보 API, 지연 상태, 게이트·좌석 저장
- 티켓 추가·삭제·이미지 뷰어·길찾기 동작 연결
- 교통편 삭제·편집 동작

이 기능들은 화면 형태가 확정된 뒤 별도 작업으로 연결한다.
