사용자가 "지금 X가 안 보여", "Y가 잘못됐어" 같은 증상을 말하면 **미완성 상태를 알리는 것**이지 그 기능을 제거하라는 뜻이 아니다. 원인을 찾아 고친다. 되돌리지 않는다.

**Why:** 탭 네비게이션 Liquid Glass 작업에서 같은 실수를 두 번 반복해 강하게 지적받았다. "메뉴는 흐리고 원형이 떠있다"는 스티키 효과 버그 리포트였는데 기능을 통째로 삭제했고, 다시 "캡슐이 안 보여"에도 또 롤백을 시도했다. 사용자가 시간을 들여 실기기로 확인해준 피드백을 버리는 행위다.

**How to apply:**
- 증상 보고 → 원인 분석 → 수정. 롤백은 선택지에 없다.
- 되돌리려면 "되돌려", "빼자", "취소" 같은 명시적 지시가 있어야 한다.
- 원인을 모르겠으면 추측으로 코드를 고치지 말고, 무엇을 확인하면 되는지 물어본다.
- 특히 네이티브/실기기 렌더링은 추측으로 반복 수정하면 화면이 계속 깨진다.
